# Arena oraja 0.4.14.111 任意test

0.4.14.110の配布系列を保ち、完成済みの未配布変更をまとめます。
本体の更新は任意、プラグイン0.0.79・ランチャー0.2.30を保持します。
stableとmandatoryは変更しません。配布管理はoraja #507です。

## 追加内容

- ハイスピードタブに通常／LR2／フローティングのモード別単一選択を集約。
  起動設定、Arenaオーバーレイ、F5プレイ設定で共通の値を使います。
  選曲中・プレイ中に方式を切り替え、各方式の値とリプレイの表示を保持します。
  NO SPEEDとリプレイ表示復元中の速度変更は制約に従います。
- BGA表示のON/OFFを読込設定から独立させ、非表示中も曲時刻に追従します。
- 設定ウィンドウをプレイ・音・表示に整理し、従来Arenaの重複ウィンドウを削除。
- 正の低残量ゲージを整数表示で0%にしない。小数対応スキンの表示と実際のゲージ値を保持。
- 終了直後のSELECT操作によるHIDDEN誤切り替えを防止。
- 任意のスクショ保存音、リプレイの初期・曲中のレーン設定再現、複数入力の押下保持。
- IR、音量、ゲージ、BGA、旧BMSの互換修正と、Lua値・文字列の再利用による負荷軽減。

未完了の投稿・ランキング契約変更は次回へ回します。本配布は対応サーバーの
投稿契約や既存成績データを変更しません。

## 検証・配布条件

統合ソースの本体テスト、両OSビルド、source ZIP、feature parity、配布済みexact
プラグインの互換ハーネスを確認します。署名状態・更新履歴・artifact identityを検証し、
ordinary body／pluginとArena version／build gate、必要なguarded reload、health、
known/unknown WSSを確認した後にtestチャンネルへ反映します。

実機の操作・表示・入力・再起動・BGA同期は運用者が確認します。自動テストの成功を
実機確認の完了とは扱いません。関連する実機確認Issueを保持します。
