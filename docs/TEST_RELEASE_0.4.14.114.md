# Arena oraja 0.4.14.114 任意test

0.4.14.113の配布系列を保ち、手元カメラの表示の修正と調整機能（#525、#526）だけを追加します。
本体の更新は任意で、Arenaプラグイン0.0.80（同じjar）とランチャー0.2.30は保持します。
stableとmandatoryは変更しません。配布管理はoraja #529です。

## 追加内容

- **二重表示の修正（#525 / PR #527）:** camera部品を持つスキン（例: IIDX33の「Hand Camera」を有効にした状態）では、
  「BGA枠に表示」がONでもBGA枠には通常のBGAを表示します。同じ映像が二重に出なくなります。
- **表示の調整（#526 / PR #528）:** すべてのカメラ表示（スキンのcamera部品とBGA枠）で、次の項目を調整できます。
  - 表示位置X/Y（表示枠に対する%）
  - 拡大率（100〜400%）
  - 切り抜き中心X/Y
  
  スキンが指定する切り抜きの内側で適用します。F5の「手元カメラ」ウィンドウではプレイ中もその場で反映し、
  ランチャーの「画面 / Video」でも変更できます。
