# ファンクションキー／テンキー機能一覧

## 使い方

選曲画面のF5（Insert）メニュー、または通常／コンパクトArenaオーバーレイの
「ファンクションキーメニューを開く」から開く。F5親メニューを閉じても一覧は残る。
一覧の閉じるボタンで終了する。既存のキー割り当てや設定ファイルは変更しない。

- 「ファンクションキー」: F1〜F12、F2長押しのMANIAC OPTIONS、
  Ctrl+F3のMD5コピー、Ctrl+Shift+F3のSHA256コピー。
- 「テンキーの機能」: テンキーに割り当て可能な全機能。実際の割り当てに関係なく
  選べる。「なし」は除外。判定タイミングの自動調整／増減はプレイ中専用なので
  無効表示にする。これはキーボード上段の数字キー一覧とは別の機能一覧。

F10のフォルダオートプレイはフォルダ選択中のみ使える。MANIAC OPTIONSを
個別設定で無効にしている場合、その入口も無効になる。F7は既存のX投稿処理を
使い、投稿先が設定済みの場合に画像を投稿するため、「投稿する」の確認を挟む。

選曲以外の画面とMANIAC OPTIONSでは一覧を閉じる。Arenaプレイ／リザルトに
操作入口を追加しない。実行は描画処理の外へ予約し、同じ選曲画面にいることを
再確認する。キー入力を合成せず、既存のテンキー処理、選曲イベント、選曲ガードを
使う。メニューがキーボード操作を受けている間はゲーム側への入力を抑止する。

## 検証

自動検証は `core:test` とmacOS ARM用 `core:shadowJar`、PRの既存CIを使う。
次の実機確認は運用者が行う。自動検証だけで実機確認済みとはしない。

- F5、通常Arena、コンパクトArenaの各入口から開き、スクロールと閉じる操作を確認。
- F5親メニューを閉じても一覧を使えること、キーボードで一覧を操作した際に
  選曲移動や演奏が誤発火しないことを確認。
- キー未割り当てでもテンキー機能を使用でき、既存キーでも同じ操作ができること。
- FPS、画面切替、保存画像、フォルダ更新、検索、フィルター、ソート、リプレイ、
  お気に入り、IR、キー／スキン設定を確認。
- MANIAC OPTIONSの無効設定、F10のフォルダ限定、判定調整の無効表示を確認。
- X投稿はキャンセル経路を確認。実際の投稿確認は運用者の明示的な操作で行う。
- Arenaの選曲固定中、マイ難易度表の一括編集中も、既存の変更／開始制限が働くこと。
- プレイ／リザルトへ移った際に一覧が閉じ、予約済み操作が実行されないこと。
- 日本語／英語、狭いウィンドウでの表示と通常プレイを確認。
