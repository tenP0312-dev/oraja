# 強制LNのON/OFF

Issue #345。ユーザー確認により、#343の常時LN/CN/HCN強制を修正する。
Issue #362は成績の保存先だけを譜面別に修正する。

## 設定と適用

- 起動前コンフィグの「BMS-IR固有設定」先頭に「強制LN」を配置する。初期OFF。
- ON: BMSの`#LNMODE`、LNチャンネル、`#LNOBJ`、bmsonヘッダとノート個別指定を
  読み込んだ後、既存ロングノートをすべてLNとして扱う。CN/HCNにも強制適用する。
- OFF: 譜面指定を保持し、未定義LNは通常のLN/CN/HCN選択に従う（#210の動作）。
- 通常の選択はON中も保持する。OFFへ戻すとその選択を再使用する。
- `PlayerConfig.bmsirForceLn`を保存する。既存設定にキーがなければOFF。
- 通常・オート・練習・コース・再読込の共通ローダーで適用する。
  ノートの時刻、レーン、ペア、キー音、譜面ファイルとハッシュは変更しない。
  LNの終端はノーツ数に含めず、判定・描画・IR送信も同じモデルを使う。
- 「ロングノート変換」は別のADD/REMOVEオプション。誤解を招いた「強制LN／」表記を除去する。
- ArenaではLNルール（ratedを含む）が強制ON、CN/HCNルールがOFF。
  個人設定で対戦ルールを上書きしない。退室時は強制設定と通常選択を復元する。
  CN/HCNルールで譜面の明示種別を選択モードへ強制変換する機能は追加しない。

## 成績・リプレイ

- OFFの成績は従来の`score.db`、MANIAC成績は`bmsir_maniac.db`。
- ONでもLNなし・元からLNの譜面は従来の成績を参照・更新する。
  未定義LNは従来の`mode`別成績を使う。ON中はLNの成績、OFFでは保存された
  選択モードの成績となり、CN/HCNモードの成績をLNへ流用しない。
- ONで明示CN/HCNをLNへ変換する譜面だけ`bmsir_forced_ln.db`、MANIACは
  `bmsir_forced_ln_maniac.db`を使う。混在譜面も一部にCN/HCNがあれば分離する。
  専用成績がなければ未プレイから開始し、既存の専用成績があれば継続する。
  OFFへ戻すと元の成績を参照する。元の成績を置換・移動・推測コピーしない。
- 以前の版が専用DBへ保存したLNなし・元からLNの成績は削除も合算もせず残す。
  今後は従来DBを参照する。MAX値からの旧記録の再分類は行わない。
- 分離対象のON用プレイ履歴は`bmsir_forced_ln_scorelog.db`と
  `bmsir_forced_ln_scoredatalog.db`。プレイヤー全体の累計統計は共有する。
  コースは構成譜面の一つでも分離対象なら専用成績を使う。
  選曲の単曲・一括読出し、キャッシュ、削除も同じ判定で切り替える。
  ハッシュだけで譜面情報のない旧APIは従来DBを参照し、選曲・MANIAC・削除の
  実動線は譜面情報のあるAPIを使う。一括読出しはDB別にまとめて取得する。
- 明示種別を変換した成績は既存の`bmsirLongNotePolicy=1`を使い、
  paired plugin #42が旧送信スナップショットと区別する。
  譜面ハッシュとIRの`lntype=0/1/2`契約は変えない。
  #362でもライブ送信のマーカー判定は維持する。共有するローカル自己ベストへ
  強制policyを付けて旧成績を無効化しない。IR送信契約は成績DBの選択と分離する。
- MANIACのリモート同期は強制policyを識別できないため、ONのローカル成績へ流用しない。
- 新リプレイは実際に強制変換したかを`bmsirForcedLongNotes`へ記録する。
  明示種別を含む譜面ではONの派生ファイル名とOFFの従来名を分ける。
  再生は現在の設定ではなく記録されたフラグ・mode・RANDOM分岐を使う。
  フラグのない旧リプレイは従来の解釈で再生する。
- #343の未配布ソースで導入した退避機構は互換コードとして残すが、
  この設定切替ではOFF行をON行へ置換する退避は発生しない。

## 回帰確認と配布

- 設定キーなしのOFF、ONの保存復元、OFFで元のCN/HCN選択に戻ること。
- 実ローダーの両入口で全BMS LNMODE × 選択LN/CN/HCN × OFF/ON/OFFを確認する。
- bmsonの個別種別、通常ノーツ、判定モデルとノーツ数、IR情報の整合。
- ON/OFFの単曲・一括・コース成績、切替後の更新とキャッシュ、リプレイの保存・再生。
- LNなし・明示LN・未定義LN・CN・HCN・bmson混在を通常選択3種で検証する。
  共有対象の更新がOFFへ戻した後も反映されること、分離対象が通常成績を流用しないこと、
  選択側だけの削除、混在した一括読込、既存専用DBの維持、MANIACの同等動作を確認する。
- リプレイは既存派生名と旧ファイルへのフォールバック、記録された変換フラグを維持する。
  成績共有を理由にリプレイファイルの移動・改名は行わない。
- Arenaの固定と退室時の設定復元。
- `core:test`とmacOS body build、リポジトリCI。
- 実機のスイッチ操作、通常/rated/各ルーム、練習・再試行・コース・旧リプレイは
  operatorが確認する。Codexはゲームや起動前コンフィグを起動しない。
- source-only。配布はBMS-Mania/IR#1184。paired plugin #42と本体を組として配布し、
  新旧Arena本体の解釈が混在しないゲートを適用する。ソース実装だけでは配布を認可しない。
