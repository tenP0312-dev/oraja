# Mod Menuの個別設定

Source: [oraja#394](https://github.com/tenP0312-dev/oraja/issues/394)、
[BMS-Mania/IR#478 添付資料](https://github.com/BMS-Mania/IR/issues/478#issuecomment-5809816681)。

## 動作

起動設定の「Mod Menuの有効/無効」ページ、またはInsertメニューの同名項目から
14項目を選択する。クラシック・サイドバーの両設定表示で利用でき、変更は
現在のプレイヤーの `config_player.json` に直ちに保存する。保存失敗は画面に通知する。
メニューの呼び出しと設定項目そのものは常に利用できる。

`modMenuSettings.filterEnabled` は初期値true。OFFでは従来の全機能を使える。
固定IDの `itemEnabled` は全14項目trueで始まり、旧設定・null・未記録項目もtrueへ
正規化する。未知IDは保持する。フィルターOFF中も個別選択を保持し、チェックは
変更不可として表示する。再ONで以前の選択を適用する。

個別OFFでは、メニュー行を描画せず、毎フレーム描画前に対象ウィンドウを閉じる。
速度・RANDOM・判定トレーナーは実行状態と編集チェックもOFFにする。
機能参照時にもフィルターを確認するため、描画以外の経路から再開しない。
ウィンドウを再有効化しても自動では開かない。

BMS-IR Arenaオーバーレイは既存の非表示処理で閉じる。フィルターで無効な間は
ホットキー・表示復元でも開けない。再有効化後は既存の表示復元操作を使い、
通常／コンパクトの最後の表示形式へ戻す。Arena接続や対戦は継続する。

MANIAC OPTIONSは編集ウィンドウと未確定ドラフトを閉じ、保存済み選択は保持する。
無効中は次の通常プレイ、選曲スコア表示、MANIAC API取得に標準設定を使用する。
旧スキンのEXTRA MODE操作でも再開できず、DP操作は通常OFF／FLIPのみ選択する。
開始済みプレイやリプレイの確定済み設定・成績IDは変更しない。

楽曲管理の `songManagerSortLastPlayed` は初期値false。プレイヤー設定から
最初のリスト構築前に復元し、プレイヤー変更時も切り替える。チェック変更と
既存の通常ソートへの切替操作で保存する。楽曲管理を無効にすると最終プレイ順は
適用されず、保存値を保持する。

## 検証と手動受入

自動テストは旧／null／部分設定、全14項目の実ファイル保存・再読込、未知ID保持、
フィルターOFF／ON、MANIAC値保持と実効停止、プレイヤー別ソート復元、
ウィンドウ閉鎖、トレーナー停止、再有効化で自動表示しないことを確認する。

オペレーターによる実機確認は別途必要：

- 起動設定の両表示方式とInsert設定から各項目を変更し、再起動後に復元する。
- 開いている各ウィンドウをOFFにし、閉鎖とトレーナー停止を確認する。
- フィルターOFFで全機能へ戻り、再ONで以前の選択を適用する。
- MANIACをOFFにした次の通常プレイが標準設定となり、再ONで保存値が戻る。
- 楽曲管理の最終プレイ順を保存し、次の起動の初回リストから適用する。
- ArenaオーバーレイをOFFにし、ホットキーでも表示されないことを確認する。
  再ONだけでは表示されず、既存の表示操作で通常／コンパクトを復元する。

ソース実装の完了はバイナリ配布・本番反映・実機受入の完了を意味しない。
