# 0.4.14.91 全5件の統合テスト配布 (#406)

0.4.14.90系列へ #310、#348、#383、#402、#403をすべて取り込む。

- コントローラー対応マイ難易度表編集。一括編集中は曲・段位・ランダム選曲の誤起動を抑止し、フォルダと確認操作は維持する。
- Scene JSONのCPUコンパイル結果を32件・元JSON16 MiB上限で再利用する。GPU資源は保持しない。
- NANTOKA MANIA単独で段位・コースを遊ぶと固定判定とDAN_NANTOKAゲージを使用する。他のMANIAC効果との組合せはコースで適用しない。通常の合否・成績・リプレイ・IR送信は保存しない。
- ADDNOTES v2は前後行の重複が少ない配置を優先する。旧リプレイ・固定seed・ランキングは旧配置を再現し、新旧を分離する。対応サーバー#1313は既存本番mainに含まれる。
- 強制LN切替後は5秒の選曲待ち後にランキングを再取得し、互換なlast-goodを表示する。旧コース永続キャッシュを復元しない。段位alias正規化プラグインの未配布変更はこの本体更新に含まない。
- 0.4.14.90の段位リザルト、Mod Menu設定、出力EQを継続する。plugin 0.0.77、launcher 0.2.29を継続する。

両OS本体と対応ソースZIPは同じ確定コミットを使う。署名、加算ゲート、安全な必要reload、health、WSS既知/未知、signed testのlive一致を確認する。

実機受入はオペレーターが行う。NANTOKA単独段位の固定判定・ゲージ、My Tableの保存・失敗時保留・編集中の誤起動抑止、Scene見た目、ADDNOTES旧新リプレイ、強制LN ON/OFF/ONの再取得、通常プレイ/IRを確認する。GUI操作をCodexが代行しない。
