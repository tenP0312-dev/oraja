# 0.4.14.90 任意テスト配布 (#404)

0.4.14.89 の配布系列を維持し、マージ済みの #393、#397、#398 を取り込む。

- 段位コースの合否をリザルト画面に表示する。
- Mod Menu の項目ごとの表示・機能停止とプレイヤー別設定保存を追加する。
- 初期OFFのSwitch方式4バンド／LR2風7バンド出力EQを追加する。PortAudio/ASIOに対応し、OpenALでは未対応を表示する。設定変更は再起動後に適用する。
- plugin 0.0.77、launcher 0.2.29、強制LNとランキング永続キャッシュを継続する。未マージPRは含めない。

両OS本体とソースZIPを同じ確定コミットから作成する。署名監査、加算ゲート、必要な保護付き再起動、WSS既知/未知プローブ、testチャネルのlive一致を確認して配布を完了する。

物理確認はオペレーターが行う。段位の合否表示、Mod Menu項目の無効化と再起動後の保存、PortAudio/ASIOでの各EQの聴感と再起動適用、OpenALの未対応表示を確認する。通常プレイ、強制LN、IRランキング表示と送信も確認する。CLIや自動テストだけでは物理確認完了と扱わない。
