# 0.4.14.89 任意テスト配布 (#390)

0.4.14.88 の配布ブランチを基点に、PR #389 の IR ランキング永続キャッシュを含める。

- 成功した曲・コースランキングをプレイヤーデータ領域へ保存し、再起動後の初回表示で復元する。
- キャッシュ済み譜面のカーソル選択だけでは通信せず、スコア送信成功後に対象ランキングのみ更新する。
- IRアカウント・接続名・譜面/コース・LN解釈をキーに含める。取得重複を抑止し、破損時はバックアップまたは再取得へ戻る。
- plugin 0.0.75、launcher 0.2.29、Force LN の0.4.14.88動作は維持する。

更新は任意。配布する両OS本体と対応ソースZIPは同じ確定コミットから作成し、署名・ゲート・必要な保護付き再起動・WSS/Pages検証を BMS-Mania/IR #1267 で記録する。

ローカル `./gradlew core:test` と PR CI は成功済み。実機では通常IRアカウントで、曲/コースランキングの初回取得後に再起動し、再取得通信なしで順位・人数・ランプが表示されることを確認する。さらに、送信成功後に対象だけ更新されること、失敗送信で以前の表示が保持されること、LN/Force LNと複数アカウントのキャッシュが混ざらないことを確認する。物理確認は運営者が行う。
