# 0.4.14.92 NANTOKA MANIA v2 任意test (#411)

0.4.14.91配布系列へPR #410のNANTOKA v2だけを追加する。

- DP皿の判定を専用幅へ変更。通常入力候補は−350msより後、+250ms以下。
- 見逃しは皿BAD外周とは独立した仮想60Hzの15フレーム超過条件。
- HCNは早い途中離しでも終点を消費する。再保持で戻るのは本体回復だけ。
- BSSはorajaの論理停止でも終点を判定する。筐体位置履歴の同一再現ではない。
- HCNの8フレーム集計と10フレーム表示を分離。同時周期の再保持でその回の空POORを維持。
- 新規成績はv2 IDへ分離。既存成績は維持し、旧リプレイはv1エンジンで再生する。
- 0.4.14.91の機能、plugin 0.0.77、launcher 0.2.29を継続。mandatoryは両方false。

同じ確定コミットから両OS本体と対応ソースZIPを作成し、plugin互換、署名/history、
加算ゲート、安全な必要reload、health、既知/未知WSS、8live metadataとdeployment markerを確認する。
サーバーソースの機能変更、stable配布、一般告知、本番データ変更は含めない。

実機受入はオペレーターが行う。DP両皿、鍵盤/SP皿、HCN途中離し後の終点消費と
再保持回復、BSS停止、旧リプレイ、新旧成績分離、単独段位、通常プレイ/IRを確認する。
GUIの起動・操作をCodexが代行しない。
