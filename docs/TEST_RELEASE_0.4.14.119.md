# Arena oraja 0.4.14.119 任意test

0.4.14.118 の全配布機能を保持し、NONSTOP MIX（#535）の改善だけを追加します。
plugin 0.0.81、launcher 0.2.30、stable、mandatory は維持します。
管理Issueは oraja #567 です。

## 変更（NONSTOP MIX）

- **選曲画面のNONSTOP MIXフォルダ**（#539）: 保存済みのセットとIRのセットを、コースのように決定ボタンだけで遊べます。
- **おまかせ生成**
  - 難しさは難易度表（☆/★）を優先し、表にない譜面はノーツ密度から見積もります。範囲は LV1–LV12 と ★1–★25 で選べます（#552）。
  - 同じ曲の別の差分は1セットに1つまでです（#552）。
  - 基準曲はセットの曲を選んでいなければ選曲画面の曲を使います。毎回違う曲から始まるようにし、ジャンルの系統（トランス・テクノなど）を選べます（#563）。
  - 「同じジャンルだけ」で曲が足りないときは段階的に広げ、条件に合う曲数を表示します（#565）。
  - 曲が入っているセットに「全部おまかせ」を適用すると新しいセットになり、前の保存済みセットを上書きしません（#555）。
  - フェード・カットのつなぎで、最後のノーツから次の曲の最初のノーツまでを短くします（#553）。
- **別の差分への入れ替え**: 曲ごとの入れ替えと、全曲を一段易しい／難しい差分にしたセットのコピー（#554）。
- **BGA**: セットごとに「BGAを使わない」を選べ、長い・重いセットでは警告します（#556）。

## 今の版の制限

- IRサーバーの NONSTOP MIX API（BMS-Mania/IR#1442）は未反映のため、IRタブと「IRのセット」は「未対応」表示です。
- BGAはセット開始時にまとめて読み込みます（次の曲だけ先読みする方式は #557）。
- テンポ合わせ・エフェクト・リプレイ保存は未対応です。Arena接続中は遊べません。
