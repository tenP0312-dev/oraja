# Arena oraja 0.4.14.113 任意test

0.4.14.112の配布系列を保ち、手元カメラの使い勝手の改善（#519、#521）だけを追加します。
本体の更新は任意で、Arenaプラグイン0.0.80（0.4.14.112と同じjar）とランチャー0.2.30は
保持します。stableとmandatoryは変更しません。配布管理はoraja #523です。

## 追加内容

- **カメラの保存と自動接続（#519 / PR #520）:**
  - 選んだカメラを、名前とOS固有ID（WindowsはDirectShowのAlternative name）で保存します。
  - 起動時、接続順やmacOSの番号が変わっても、同じカメラを探して自動でつなぎます。
  - 見つからない、または区別できないときは、別のカメラにはつなぎません。
- **抜き差しの自動接続（#519）:**
  - カメラを表示している画面（プレイ中を含む）で、後から挿したカメラや挿し直したカメラに自動でつなぎます。
  - 毎フレームは試さず、2秒、4秒、8秒、以降10秒ごとに間隔を広げます。
- **BGA枠に表示（#521 / PR #522）:**
  - camera部品のないスキンでも、プレイ画面のBGA枠にBGAの代わりに手元カメラを映せます。初期OFFです。
  - 映らない間は通常のBGAを表示します。
- **F5メニュー（#521）:**
  - Modメニューの「手元カメラ」ウィンドウで、次の項目をゲーム中に変更できます。
    - 有効・無効
    - BGA枠に表示
    - 使用するカメラ（一覧の更新を含む）
    - サイズ
    - FPS
    - 左右反転
- スコア、リプレイ、IR、Arena通信にはカメラ映像を追加しません。
