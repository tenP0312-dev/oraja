# Arena oraja 0.4.14.116 任意test

0.4.14.115の配布系列を保ち、NONSTOP MIX（#535 / PR #536）だけを追加します。
本体の更新は任意で、Arenaプラグイン0.0.80（同じjar）とランチャー0.2.30は保持します。
stableとmandatoryは変更しません。配布管理はoraja #537です。

## 追加内容

- **NONSTOP MIX:** 選曲画面のF5 → Modメニュー →「NONSTOP MIX」で、複数の曲の区間をつないだセットを作り、1回の通しプレイとして遊べます。
  - つなぎは「混ぜる」（音量の入れ替え）・フェード・カットから選べます。おまかせ生成もあります。
  - 記録はセットごとにローカルへ残り、通常の曲の記録やスコア送信には入りません。
  - 詳しくは [NONSTOP_MIX.md](NONSTOP_MIX.md)。

## 今の版の制限

- テンポは合わせません。EQやエコーなどのエフェクトはなく、音量カーブのみです。
- 鍵盤モードの違う曲は同じセットに入れられません。判定・配置オプションはセット全体で1つです。
- FREQ・MANIAC OPTIONS・7K TO 9Kはミックス中は使えません。リプレイ保存はまだありません。
- Arena接続中は遊べません。
- 開始時に全曲の音源を読み込むため、曲数が多いとメモリと開始時間が増えます（12曲を超えると注意を表示）。
- IR連携はサーバー側が未対応のため、IRタブは「未対応」と表示されます。ローカルの編集・保存・プレイ・記録は使えます。
