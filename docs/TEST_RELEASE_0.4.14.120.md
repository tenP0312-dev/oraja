# Arena oraja 0.4.14.120 任意test

0.4.14.119 の全配布機能（NONSTOP MIX を含む）を保持し、main にだけ入っていた次の変更を取り込みます。
plugin 0.0.81、launcher 0.2.30、stable、mandatory は維持します。
管理Issueは oraja #569 です。main 全体のマージは配布系列との差が大きいため行わず、PR単位で `cherry-pick -m 1 -x` しました。

## 変更

- **ハイスピード**（#506、#509）: 専用タブで鍵盤モードごとに通常・LR2・フローティングを選べ、プレイ中に切り替えられます。
  ハイスピードはF5のModメニューの独立したウィンドウになり、フローティングハイスピードは緑数字で決めます。BGAの表示も切り替えられます。
- **選曲画面のArenaオーバーレイ**（#509）: ハイスピード・BGA・難易度表編集の置き場所を整理しました（難易度表編集はF5の独立ウィンドウ）。
- **余韻スキップ**（#511）: 最後のノーツの後すぐにプレイを終える設定。曲の音はリザルトまで鳴り続けます。
- **MANIAC OPTIONS**（#513）: 見た目だけを崩す12項目を削除しました。
- **スキン選択のプレビュー**（#328、#329）: 読み込み後の最初の画面から始め、実際の画面と同じ動きにします。
