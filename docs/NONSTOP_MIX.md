# NONSTOP MIX（Issue #535）

曲をDJセットのようにつなぎ、曲間のロードや個別リザルトを挟まずに通しで遊ぶモードです。
選曲画面で **F5 → Modメニュー →「NONSTOP MIX（曲をつないで連続プレイ）」** から開きます。
マウスでの操作を前提にしたウィンドウです（キーボードでも項目移動はできます）。

## できること

| 機能 | 内容 |
| --- | --- |
| 手動で作る | 曲の追加・並べ替え・削除、使う区間（開始/終了）、つなぎ方、重ねる長さ、譜面が次の曲に替わる位置、音量カーブ、曲ごとの音量補正 |
| おまかせ生成 | 曲選び・曲順・使う区間・つなぎを自動で作る（AIモデルは使わず、譜面の小節線・テンポ・密度・ロングノーツ・ジャンル表記から決める） |
| 部分的におまかせ | 今の曲で曲順とつなぎだけ／つなぎだけ／選んだ範囲の曲だけ入れ替え。固定した曲・区間・つなぎは変えない |
| 試聴・試奏 | つなぎだけをオートで聴く、つなぎだけ叩く、ある曲から最後まで叩く。本番と同じ組み立て結果を使う |
| 通しプレイ | 全曲を1本の譜面として連続で遊ぶ。最後にセット全体のリザルトと曲ごとの内訳を表示 |
| 保存 | 名前付きで保存・複製・削除、元に戻す/やり直す、編集中の下書きを自動保存 |
| 共有 | レシピ（音源なし・ファイルの場所なし）をクリップボードでやり取り。IRで公開・検索・取り込み・そのまま遊ぶ・ランキング |
| 記録 | セット専用に保存。通常の譜面記録・コース・段位・IRの通常スコアには入らない |

## 画面

- **セット編集**: 左が曲とつなぎの一覧、右が選んだ項目の詳細。
  - 曲を選ぶと、曲全体の「音の多さ（青）」「ノーツ密度（白線）」「小節線（8小節ごとに濃い線）」
    「ロングノーツ（黄色）」が表示されます。**左クリックで開始、右クリックで終了**を指定できます。
    「小節にそろえる」が入っていると小節線に吸着します。
  - つなぎを選ぶと、前後2曲の重なりと音量カーブ、譜面交代位置（赤線）が表示されます。
    グラフをクリックすると譜面交代位置を動かせます。ロングノーツの途中は選べません。
  - 「確認が必要な点」に、ロングノーツが切れる位置などの問題が出ます。クリックするとその項目に移動します。
    エラーが残っている間は通しプレイを始めません（試聴・試奏はできます）。
- **おまかせ生成**: 長さ・ジャンルの決め方・レベル範囲・難しさの流れ・曲の使い方・混ぜる長さなどを選んで「作る」。
  結果は「この案を適用」するまでセットを変えません。適用後も「元に戻す」で戻せます。
- **保存済みセット** / **IRで探す・公開** / **記録**。

## つなぎ方

| 種類 | 音 | 譜面 |
| --- | --- | --- |
| 混ぜる | 2曲を重ね、音量を入れ替える | 重なりの中の「譜面交代位置」で次の曲に替わる |
| カット | 前の曲を止めて次の曲をすぐ始める（ぶつ切れ防止の短い減衰あり） | つなぎ目で替わる |
| フェードアウトして次へ | 前の曲を指定の長さで下げてから次の曲 | 次の曲の頭で替わる |
| 止めてフェードイン | 前の曲を止め、次の曲を下から上げる | 次の曲の頭で替わる |

重なっている間、叩いていない側の曲のキー音は背景音として鳴ります。同じ音が二重に鳴ることはありません。

## 今の版の制限

- **テンポは合わせません（音程を保った伸縮は未実装）。** テンポが近い曲どうしは「混ぜる」、離れている曲は
  フェードやカットにするのが基本です。おまかせ生成もこの方針で選びます。
- EQ（低音の入れ替え）やエコーなどのエフェクトはありません。音量カーブのみです。
- 鍵盤モードの違う曲は同じセットに入れられません。
- 判定はセット全体で1つです（「曲の平均」「一番きびしい曲」も選べます）。ゲージはTOTALをセット全体のノーツ数から
  計算し、倍率で調整できます。
- 再生速度変更（FREQ）・MANIAC OPTIONS・7K TO 9Kはミックス中は使えません。ランダム等の配置オプションはセット全体にかかります。
- ミックスのリプレイ保存はまだありません。
- Arena接続中は遊べません。
- 区間の途中から始めると、その前から鳴っていた長い音は鳴りません。
- 開始時にセット全曲の音源をまとめて読み込みます（次の曲だけ先読みする方式は未実装）。曲数が多いとメモリを多く使い、
  開始まで時間がかかります。12曲を超えると画面に注意を出します。
- IR連携はサーバー側（BMS-Mania/IR）の対応が必要です。対応前は「このIRサーバーはNONSTOP MIXにまだ対応していません」と表示され、
  ローカルでの編集・保存・プレイ・記録は使えます。API仕様は [NONSTOP_MIX_IR_API.md](NONSTOP_MIX_IR_API.md)。

## 保存場所

`<プレイヤーフォルダ>/<プレイヤー名>/nonstopmix/`

- `sets/<id>.json` 保存したセット（ローカルの譜面パスを含む）
- `draft.json` 編集中の下書き
- `records.jsonl` 記録（1行1プレイ）

## 仕組み（開発者向け）

- `MixPlan` / `MixTrack` / `MixTransition`: 編集対象。手動もおまかせもIRもこの形。
- `MixCompiler`: 曲ごとの譜面を1本の譜面に合成。曲ごとに時刻をずらし、譜面を持つ曲以外のノーツは背景音へ。
  音源名には `nsmix/<曲番号>/` を付け、`MixSongResource` が各曲のフォルダ（アーカイブ含む）へ解決する。
  ロングノーツが交代位置・区間の端をまたぐとエラーとして報告し、黙って削らない。
- `CompiledMix.gain` と `MixRuntime`: 曲ごとのフェード。鳴らし始めの音量と、鳴っている音の音量を毎フレーム追従。
- `MixTrackAnalysis` / `MixJoinPlanner` / `MixSequencer` / `MixGenerator`: おまかせ生成。
- `MixStore` / `MixResult` / `MixPlayRecorder`: 記録。`MixIrClient` + `BMSIRNonstopMixTransport`: IR。
- `NonstopMixMenu`: 画面。
