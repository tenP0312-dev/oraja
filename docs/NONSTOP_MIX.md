# NONSTOP MIX（Issue #535）

曲をDJセットのようにつなぎ、曲間のロードや個別リザルトを挟まずに通しで遊ぶモードです。
選曲画面で **F5 → Modメニュー →「NONSTOP MIX（曲をつないで連続プレイ）」** から開きます。
マウスでの操作を前提にしたウィンドウです（キーボードでも項目移動はできます）。
作ったセットやIRのセットを遊ぶだけなら、選曲画面の **「NONSTOP MIX」フォルダ** からコントローラーだけで遊べます（#539、下記）。

## できること

| 機能 | 内容 |
| --- | --- |
| 手動で作る | 曲の追加・並べ替え・削除、使う区間（開始/終了）、つなぎ方、重ねる長さ、譜面が次の曲に替わる位置、音量カーブ、曲ごとの音量補正 |
| おまかせ生成 | 曲選び・曲順・使う区間・つなぎを自動で作る（AIモデルは使わず、譜面の小節線・テンポ・密度・ロングノーツ・ジャンル表記から決める） |
| 部分的におまかせ | 今の曲で曲順とつなぎだけ／つなぎだけ／選んだ範囲の曲だけ入れ替え。固定した曲・区間・つなぎは変えない |
| 差分の入れ替え | 曲ごとに同じ曲の別の差分へ替える。セット全体を一段易しい／難しい差分にした別のセットを作る |
| 試聴・試奏 | つなぎだけをオートで聴く、つなぎだけ叩く、ある曲から最後まで叩く。本番と同じ組み立て結果を使う |
| 通しプレイ | 全曲を1本の譜面として連続で遊ぶ。最後にセット全体のリザルトと曲ごとの内訳を表示 |
| 保存 | 名前付きで保存・複製・削除、元に戻す/やり直す、編集中の下書きを自動保存 |
| 共有 | レシピ（音源なし・ファイルの場所なし）をクリップボードでやり取り。IRで公開・検索・取り込み・そのまま遊ぶ・ランキング |
| 記録 | セット専用に保存。通常の譜面記録・コース・段位・IRの通常スコアには入らない |
| 選曲画面から遊ぶ | 「NONSTOP MIX」フォルダから保存済み・IRのセットを選び、決定ボタンだけでプレイ・オート再生（#539） |

## 画面

- **セット編集**: 左が曲とつなぎの一覧、右が選んだ項目の詳細。
  - 曲を選ぶと、曲全体の「音の多さ（青）」「ノーツ密度（白線）」「小節線（8小節ごとに濃い線）」
    「ロングノーツ（黄色）」が表示されます。**左クリックで開始、右クリックで終了**を指定できます。
    「小節にそろえる」が入っていると小節線に吸着します。
  - つなぎを選ぶと、前後2曲の重なりと音量カーブ、譜面交代位置（赤線）が表示されます。
    グラフをクリックすると譜面交代位置を動かせます。ロングノーツの途中は選べません。
  - 「確認が必要な点」に、ロングノーツが切れる位置などの問題が出ます。クリックするとその項目に移動します。
    エラーが残っている間は通しプレイを始めません（試聴・試奏はできます）。
  - セットの設定「BGAを使わない」をオンにすると、BGA・レイヤー・背景画像（BACKBMP）を読み込まずに遊びます。
    セットのレシピに保存されますが、記録は同じセットとして残ります。
  - 曲を選ぶと「別の差分に替える」から、同じ曲フォルダにある同じ鍵盤モードの別の譜面（難易度表記・レベル・ノーツ数）を選べます。
    使う区間とつなぎはそのままで、区間は新しい譜面の長さに収めます（終了が譜面より後なら「最後まで」）。
    固定した#RANDOMの分岐は新しい譜面では引き直します。「元に戻す」で戻せます。
  - 「セットの設定」の「全曲を一段易しい差分に」「一段難しい差分に」は、各曲をレベル→ノーツ数→難易度表記の順で
    一段となりの差分に替えた**新しいセット**を「(易)」「(難)」付きの名前で保存して開きます（元のセットはそのまま）。
    そういう差分がない曲・ライブラリにない曲はそのまま残り、画面に一覧が出ます。
    譜面が変わるのでセットの記録も別になります。IR公開済みのセットから作ったものは未公開の新しいセットになります。
- **おまかせ生成**: 長さ・ジャンルの決め方・レベル範囲・難しさの流れ・曲の使い方・混ぜる長さなどを選んで「作る」。
  結果は「この案を適用」するまでセットを変えません。適用後も「元に戻す」で戻せます。
  曲が入っているセットに「全部おまかせ」を適用すると、新しいセットになります（前のセットは保存済みセットに残ります）。
  曲順とつなぎ／つなぎだけ／範囲のおまかせは、今のセットの編集です。
  - 難易度は1本の軸で扱います（通常 ☆1–☆12 の上に発狂 ★1–★25。☆12 は ★1 のすぐ下）。
    譜面の位置は、読み込んでいる難易度表（★/☆、▼/▽ のフォルダ）を最優先し、表にない譜面は
    平均密度（ノーツ数÷長さ）と最大密度から推定します。#PLAYLEVEL は長さも分からないときだけ使います。
  - 「難易度の目盛り」で「通常 LV1–LV12」か「発狂 ★1–★25」を選び、レベルの範囲を1段ずつ決めます。
    難しさの流れはこの範囲の中で付きます。LV1 は LV0 を、★1 は ★0・★? を、★25 は ★★ を含みます。
  - 1つのセットに同じ曲は1譜面だけです。同じフォルダの譜面、または曲名とアーティストが同じ譜面
    （[ANOTHER] や -INSANE-、obj: などの表記を除いて比べる）を同じ曲とみなします。固定した曲も数えます。
    「今の曲で曲順とつなぎ」は今の曲を並べ替えるだけなので、この制限をかけません。
  - 「ジャンルの系統」でトランス・テクノ・ハードコア・ドラムンベース・ハウス・アートコア・ユーロビート・Jコア・
    ポップ・ロックなどを選べます。系統は #GENRE の表記ゆれ（Drum'n'Bass / DnB / ドラムンベース など）を
    キーワードでまとめて判定し、「同じジャンルだけ」なら系統の曲だけ、「近いジャンルも」なら系統の曲を優先します。
    系統を選んでいる間は自由入力のジャンルは使いません。1つのジャンルが複数の系統に入ることもあります（Techno Pop）。
  - 「同じジャンルだけ」で目標の長さに届く曲がないときは、1曲だけのセットにせず段階的に広げます（#565）：
    名前の一部が同じジャンル（Brutal Hardcore → Hardcore）→ 同じ系統 → 近いジャンル優先でほかのジャンル。
    広げたときは結果の注意に「ジャンル「○○」の曲がN曲しかないため…」と出ます。系統を選んでいるときは系統 → ほかのジャンルの順です。
  - ジャンル入力・系統の下に、条件に合う曲数（同じジャンル／名前の一部が同じ／同じ系統。1曲1つで数える）を表示します。
  - 「基準曲から始める」は、セットで選んでいる曲を最初の曲にします。セットの曲を選んでいなければ（空のセットなど）
    選曲画面で選んでいる曲を使います。どちらもなければ注意を出して作りません。空のセットは基準曲の鍵盤モードになります。
  - 毎回同じ案にならないよう、最初の曲は条件によく合う曲の中からランダムに選び、各曲に乱数のゆらぎを加え、
    ほぼ同じ良さの案からランダムに1つを選びます。直近に作った案（このセッションの5件）の曲と保存済みセットの曲は
    少しだけ選ばれにくくなります。固定した曲と難しさの流れはそのまま守ります。
- **保存済みセット** / **IRで探す・公開** / **記録**。

## 選曲画面のNONSTOP MIXフォルダ（#539）

コースを遊ぶときと同じく、選曲画面のバーと決定ボタンだけで遊べます。

- ルートの **「NONSTOP MIX」** に、保存済みのセット（新しい順）と、最後に **「IRのセット」** フォルダが並びます。
  - セットのバーはコースと同じ見た目で、自己ベストのクリアをランプで表示します。持っていない曲があるセットは欠けた譜面の見た目になります。
- セットに入ると次の行が並びます。
  - 「プレイ: セット名」→ 決定で準備を始め、準備ができたらそのまま始まります。「オートで通し再生」も同じです。
  - 準備中は進み具合の行（決定で更新）と「準備をやめる」の行。フォルダを離れると、準備ができても始めません。
  - 曲数・長さの目安・判定、自己ベスト、曲の一覧（持っていない曲は欠けた見た目）。
  - 持っていない曲があるとき、または遊べない問題があるときは始めません。直すのはF5のエディターです。
- 「IRのセット」は、入るとIRに一覧を問い合わせます（1分間は前の結果を使います）。
  - IRサーバーが未対応の間は「このIRサーバーはNONSTOP MIXにまだ対応していません」の行だけが出ます。決定でもう一度問い合わせます。
  - 対応後は公開セットが並び、入るとセットを取得して保存済みセットに加え（同じ版は1回だけ）、上と同じ行で遊べます。
- Arena接続中・対戦準備中は始めません。セットの作成と編集はこれまでどおりF5のエディターで行います。

## つなぎ方

| 種類 | 音 | 譜面 |
| --- | --- | --- |
| 混ぜる | 2曲を重ね、音量を入れ替える | 重なりの中の「譜面交代位置」で次の曲に替わる |
| カット | 前の曲を止めて次の曲をすぐ始める（ぶつ切れ防止の短い減衰あり） | つなぎ目で替わる |
| フェードアウトして次へ | 前の曲を指定の長さで下げてから次の曲 | 次の曲の頭で替わる |
| 止めてフェードイン | 前の曲を止め、次の曲を下から上げる | 次の曲の頭で替わる |

重なっている間、叩いていない側の曲のキー音は背景音として鳴ります。同じ音が二重に鳴ることはありません。

おまかせ生成がカット・フェードを選んだつなぎでは、前の曲を最後のノーツ（ロングノーツの終点を含む）の
次の小節線で止め、次の曲を最初のノーツがある小節の頭から始めます。静かなアウトロやイントロは使わず、
つなぎ目でノーツが途切れる長さはおおむね2小節以内です。混ぜるつなぎ、区間を固定した曲、固定したつなぎは
変えません（#553）。

## 今の版の制限

- **テンポは合わせません（音程を保った伸縮は未実装）。** テンポが近い曲どうしは「混ぜる」、離れている曲は
  フェードやカットにするのが基本です。おまかせ生成もこの方針で選びます。
- EQ（低音の入れ替え）やエコーなどのエフェクトはありません。音量カーブのみです。
- 鍵盤モードの違う曲は同じセットに入れられません。
- 判定はセット全体で1つです（「曲の平均」「一番きびしい曲」も選べます）。ゲージはTOTALをセット全体のノーツ数から
  計算し、倍率で調整できます。
- 再生速度変更（FREQ）・MANIAC OPTIONS・7K TO 9Kはミックス中は使えません。ランダム等の配置オプションはセット全体にかかります。
- ミックスのリプレイ保存はまだありません。
- Arena接続中は遊べません。
- 区間の途中から始めると、その前から鳴っていた長い音は鳴りません。
- 開始時にセット全曲の音源をまとめて読み込みます（次の曲だけ先読みする方式は未実装）。曲数が多いとメモリを多く使い、
  開始まで時間がかかります。12曲を超えると画面に注意を出します。
- BGA（動画・画像）も開始時に全曲分を読み込みます（全動画を開き、画像は256枚までのキャッシュ）。12曲を超える、
  約20分を超える、BGA動画が合計6本以上、またはBGA画像が合計200枚以上のセットでBGAを使っていると、編集画面と
  プレイ開始前に「BGAを使わない」を勧めます。次の曲のBGAだけを読み込む方式は未実装です
  （[tenP0312-dev/oraja#557](https://github.com/tenP0312-dev/oraja/issues/557)）。
- IR連携はサーバー側（BMS-Mania/IR）の対応が必要です。対応前は「このIRサーバーはNONSTOP MIXにまだ対応していません」と表示され、
  ローカルでの編集・保存・プレイ・記録は使えます。API仕様は [NONSTOP_MIX_IR_API.md](NONSTOP_MIX_IR_API.md)。

## 保存場所

`<プレイヤーフォルダ>/<プレイヤー名>/nonstopmix/`

- `sets/<id>.json` 保存したセット（ローカルの譜面パスを含む）
- `draft.json` 編集中の下書き
- `records.jsonl` 記録（1行1プレイ）

## 仕組み（開発者向け）

- `MixPlan` / `MixTrack` / `MixTransition`: 編集対象。手動もおまかせもIRもこの形。
- `MixCompiler`: 曲ごとの譜面を1本の譜面に合成。曲ごとに時刻をずらし、譜面を持つ曲以外のノーツは背景音へ。
  音源名には `nsmix/<曲番号>/` を付け、`MixSongResource` が各曲のフォルダ（アーカイブ含む）へ解決する。
  ロングノーツが交代位置・区間の端をまたぐとエラーとして報告し、黙って削らない。
- `CompiledMix.gain` と `MixRuntime`: 曲ごとのフェード。鳴らし始めの音量と、鳴っている音の音量を毎フレーム追従。
- `MixTrackAnalysis` / `MixJoinPlanner` / `MixSequencer` / `MixGenerator`: おまかせ生成。
  `MixDifficulty` が難易度表の位置・密度推定を1本の軸（☆n = n、★n = 12 + n）にまとめる。
  `MixGenreFamily` がジャンルの系統とその表記キーワードを持つ。
- `MixChartSwap`: 差分の候補（同じ`folder`・同じ鍵盤モード）、一段易しい／難しい差分の選択、セット全体の差分替え。
- `MixStore` / `MixResult` / `MixPlayRecorder`: 記録。`MixIrClient` + `BMSIRNonstopMixTransport`: IR。
- `NonstopMixMenu`: 画面。
