# Arena oraja 0.4.14.115 任意test

## 追加内容

- **切り抜き位置:** 拡大率100%でも、スキンが決めた切り出し窓（例: IIDX33の帯）を、カメラ映像全体の中で上下左右に動かせます。
  - 50がスキンの位置です。スキンのCrop Offsetに加算されます。
  - 窓は映像の端で止まります。
- **枠の中で切り落とし:** 表示位置でずらしても、スキンのカメラ枠（BGA枠表示ではBGA枠）の外には描きません。
- **上下反転:** 「左右を反転する」の隣に「上下を反転する」を追加しました。両方ONで180度回転になります。
  - その場で反映されます。
  - 切り抜き位置は反転後の見た目どおりに動きます。
