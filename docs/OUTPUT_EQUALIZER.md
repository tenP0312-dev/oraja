# 出力イコライザー

音声設定（従来画面／サイドバー画面）でOFF、Switch方式、LR2風を選ぶ。
各方式のゲインは独立保存し、方式を切り替えても保持する。初期状態はOFF・全バンド0 dB。
スライダーと数値入力で各±12 dBを調整できる。操作刻みは0.5 dB。
「バンドを0 dBに戻す」は現在の方式のバンドだけを戻す。
共通プリアンプは−24〜0 dB。OFFではプリアンプも適用しない。

| 方式 | 中心周波数 Hz | Q |
| --- | --- | --- |
| Switch | 100 / 400 / 1600 / 6000 | 1 |
| LR2風 | 63 / 160 / 400 / 1000 / 2500 / 6300 / 16000 | 1.5 |

いずれもピーキングフィルターを直列適用する独自Java DSP。
Switchプレイヤーの `SoundEffector.cpp` のEQ設定と、
[OpenLR2のEQ設定](https://github.com/GOMazk/OpenLR2/blob/main/LR2/En_audio.cpp)を参考にした。
OpenLR2のソースコードやFMODを取り込んでいない。
周波数・ゲイン・Qの操作仕様を合わせるもので、FMODとの波形完全一致は未検証。
SwitchのVEFX・FILTER・HEADPHONE VOLUMEやOpenLR2のFXスロットは対象外。

## 音声経路

PortAudio／ASIO（WASAPI共有・排他を含む）のPCM合成後、デバイスへの書き込み前に
システム音・キー音・BGM・試聴音をまとめて処理する。
既存の音量・ラウドネス正規化・ピッチ処理はそのまま。
OpenALの経路ではEQを適用せず、画面に未対応を表示する。
出力方式は自動変更しない。OpenAL選択時も方式とゲインを保存でき、
PortAudio／ASIOへ変更して本体を再起動すると保存値が適用される。

設定は音声ドライバー作成時にスナップショットし、変更は本体の再起動後に適用する。
音声スレッドでの係数再計算・メモリ確保・ロック・追加バッファリングはない。
左右のフィルター履歴は独立し、出力バッファをまたいで維持する。
OFFおよび全バンド0 dB・プリアンプ0 dBではPCMに一切手を加えない。
判定タイミング・スコア・リプレイの仕様は変更しない。

低サンプルレートではSwitchのHIを `min(6000, sampleRate×0.4)` とする。
LR2風ではNyquist以上のバンドを素通しにし、別の周波数へ移さない。
通常の44.1／48 kHzでは全バンドを使用できる。
自動音量補正やリミッターは加えない。増幅で出力範囲を超える場合は
プリアンプを下げる。負のプリアンプはフィルター前に適用する。

## 検証

- 44.1／48 kHzで各バンドの中心周波数の正弦波を処理し、−12／＋6／＋12 dBを測定。
- Qの違い、左右独立性、バッファ境界での連続性、プリアンプ、低レート安定性。
- 旧設定のOFF既定値、2方式のJSON保存・復元、不正値補正。
- FXML、日英リソース、サイドバーのワークスペース登録を非GUIで確認。

実機聴感・音切れ・設定画面の操作確認はオペレーターによる手動確認待ち。
従来／サイドバーで切替→値変更→保存→再起動、各音声種別への適用、
44.1／48 kHz、PortAudio／ASIO／WASAPI排他、OpenALの未対応表示を確認する。
このソース変更だけではランチャー配布・リリース公開を行わない。
